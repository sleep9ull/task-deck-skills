# 监控页界面规范

目标用户是发起任务、偶尔回来检查进展的人。页面要先回答：还在运行吗、做到哪里、有哪些异常、结果在哪里。

采用 Vercel / Geist 风格的克制布局，不复制其标识。这里交付可直接打开的 HTML，使用原生语义控件与 CSS；无需为了组件外观引入 React、Tailwind 构建链或外部 CDN。

- 单页顶栏和任务标题，无默认侧边栏。桌面中间宽度约 1200px，手机按列堆叠。
- 白/浅灰底、近黑文字、1px 中性边框、6–10px 圆角；用留白和字体层级分组。
- 系统 sans 字体；ID、时间、主机与数值用系统 mono。字体加载不依赖网络。
- 顶部四个指标：已处理、成功、需关注、剩余。进度条表达真实比例，不添加装饰图表或虚构趋势。
- 总进度下方展示外部 AI API 全任务预估：服务与模型名称、输入 token、输出 token、对应币种成本及单价。区分尚未估算和无需调用，美元与人民币分别展示。
- 主区为可筛选、可搜索的批次表，旁边或下方为近期事件与结果入口。
- 状态用少量语义色并附文字。进度、新鲜度、终态与“完成但有缺口”分开表达。
- 启动前、空计划、空筛选、状态过期、任务失败与完成均有明确文案。显示最新业务时间与进程核验时间。
- 默认只读；刷新、筛选、查看结果必须可用。暂停/取消只有连接了经过授权的真实控制通道才显示按钮；静态页面不伪造控制功能。
- 键盘 focus 清晰，输入有 label，状态文字不只靠颜色；表格在窄屏内横向滚动，避免整页溢出。
- 默认 15 秒自动刷新，可关闭。刷新保留搜索、筛选和滚动位置；页面不执行相邻 JSON 里的代码。

验收至少在桌面与手机尺寸检查一次，测试筛选、空结果、终态和状态过期。渲染来自任务的名称、事件和路径时使用 textContent/安全编码，避免输入成为 HTML 或可执行链接。
